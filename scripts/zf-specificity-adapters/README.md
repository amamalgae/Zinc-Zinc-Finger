# External ZF specificity adapters

Adapters in this directory are research-only until benchmark graduation criteria are met.

Planned order:

1. Persikov et al. 2015 B1H nearest-neighbour (`10.1093/nar/gku1395`).
2. Gupta et al. 2014 ZFModels (`10.1093/nar/gku132`) if a reproducible archival model artifact is obtainable.
3. DeepZF PWMpredictor (`10.1093/bioinformatics/btac469`) as an external comparator.

Do not add model outputs copied from a web service without provenance. Do not fit model parameters to the 21 Bhakta activity labels and then report the same-label performance as validation.
